# Ejemplos

Proyectos de muestra para mostrar la app.

## Cargar un ejemplo
1. Abrir la app (`iniciar.bat` o `npm run dev`).
2. Menú del proyecto → **Importar respaldo**.
3. Elegir el archivo `.json` de respaldo de esta carpeta (`*.tesis.json` o `*.emergent.json`).

## Guardar un proyecto nuevo como ejemplo
1. En la app: menú del proyecto → **Descargar respaldo completo**.
2. Mover el archivo `.tesis.json` descargado a esta carpeta.
3. `git add ejemplos && git commit -m "docs: ejemplo de proyecto"`.
